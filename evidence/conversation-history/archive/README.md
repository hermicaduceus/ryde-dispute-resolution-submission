## Scope and format

- At the 12 October export cutoff, discovered 67 Ryde-related JSONL logs. All 56 with both recorded user and assistant messages are exported. The remaining 11 one-sided/empty logs are listed in `manifest.json`, not silently discarded; originals remain private.
- Each session has a Markdown reading copy and scrubbed JSONL containing every saved user/assistant message and every recorded tool call/result.
- Automatic compaction checkpoints, task notifications, local slash-command display and empty messages are retained here. They are labelled as recorded system/local activity, not presented as human-authored messages.
- Reasoning, file snapshots and provider/internal metadata are excluded, with omissions counted in the manifest. This is conversation/tool history, not a byte-for-byte dump of the entire raw session store.
- Tool outputs are preserved as recorded. Separate persisted-output files referenced by those outputs and binary attachments are not bundled. These exports cannot recover material absent from the source logs.
- Privacy replacements follow the parent README. No content is summarized or rewritten; the excerpt column below is the start of the first ordinary user-side task prompt, not a generated description. Automatic filtering is not a final privacy audit.
- Original source hashes and export hashes are in `manifest.json`. Original logs remain in the private CodeBuddy store. The seven selected sessions in the parent folder are untouched and are also represented here.

## Audit and presentation notes

- Additional privacy replacements mask lowercase OS username, macOS per-user temp roots, numeric CodeBuddy uid fragments and the export workspace. Original private logs are unchanged.
- Both selected and archive copies use the same content-aware label vocabulary. Machine summaries/notices, local command/skill expansions and provider errors are distinguished from ordinary recorded user-side messages. A mixed carrier is labelled as such without claiming who authored its trailing instructions.
- Each message is blockquoted; machine/XML blocks are fenced literally so tags or embedded headings cannot hide text or create false conversation boundaries. Nonprinting controls are shown as literal \uNNNN in Markdown; their original encoded values remain in JSONL.
- Automatic checkpoints quote earlier conversation and sometimes tool arguments. Those quotations are retained as machine text, not fresh human turns.
