# Build briefs

Each file here is the brief a CodeBuddy build session worked from: the allowed files, the
failing tests it had to turn green, and the rules for that round. They are kept as a record
of how the system was built, not as current documentation. Where a brief and the code
disagree, the code and the documents one level up (`docs/`) are current.

Files are named by session (`session-<n>-brief.md`, plus session two's `session-two-kickoff.md`) up to session twenty-five, then by work
item (`w<nn>-<topic>-brief.md`). The two `*-acceptance-manifest.json` files list the
acceptance checks for the W16 driver-intake build and its repair round.
